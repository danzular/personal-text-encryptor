# Changelog

Semua perubahan penting pada Personal Text Encryptor dicatat di file ini.

Format catatan mengikuti versi aplikasi. Rincian yang tidak dapat dipastikan dari implementasi final tidak diasumsikan di sini.

## [V1.2]

### Ditambahkan
- Satu aplikasi HTML untuk menyediakan dua mode enkripsi: **PTE1 — Deterministic** dan **PTE2 — GCM**.
- Gerbang akses pada halaman awal dengan tanggal yang mengacu pada layanan waktu server.
- Penamaan/penempatan mode PTE1 di sisi kiri dan PTE2 di sisi kanan.

### Dipertahankan
- Antarmuka bertema gelap.
- Pendekatan aplikasi satu file HTML.
- Penggunaan fixed salt yang harus konsisten dengan spesifikasi implementasi V1.2.

### Catatan
- V1.2 ditujukan untuk dipublikasikan melalui GitHub Pages.
- Website GitHub Pages harus dianggap publik, sekalipun repository sumber disetel Private.
- Catatan ini merangkum target dan keputusan proyek; verifikasi akhir tetap perlu dilakukan terhadap file HTML V1.2 yang benar-benar dirilis.

## [V1.1]

### Catatan
- Versi sebelumnya menjadi dasar pengembangan aplikasi dengan tema gelap, dua pilihan metode enkripsi, dan gerbang akses awal.
- Rincian perubahan V1.1 tidak dirinci lebih lanjut karena changelog historis lengkap belum tersedia.
