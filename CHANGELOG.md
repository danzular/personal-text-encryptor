# Changelog

All notable changes to Personal Text Encryptor are documented in this file.

Entries follow the application's version numbers. Details that cannot be confirmed from the final implementation are not assumed.

## [V1.2]

### Added
- A single HTML application providing two encryption modes: **PTE1 — Deterministic** and **PTE2 — GCM**.
- An access gate on the landing page that uses a date obtained from a server time service.
- PTE1 is positioned on the left and PTE2 on the right.

### Retained
- Dark user interface.
- Single-file HTML application approach.
- Fixed-salt usage, which must remain consistent with the V1.2 implementation specification.

### Notes
- V1.2 is intended for publication through GitHub Pages.
- A GitHub Pages website should be treated as public, even if its source repository is private.
- These notes summarize the project's stated targets and decisions. The actual released V1.2 HTML file should be checked to confirm the implemented behavior.
